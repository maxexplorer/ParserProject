# Парсер UTZ74

Парсер обходит каталог сборочных схем Т-130/Т-170, извлекает строки таблиц деталей и формирует Excel в том же формате из 46 колонок, что и `shop_uralaz_site`.

Одинаковые артикулы, встречающиеся в нескольких сборках, записываются в результат один раз. Название сборки, позиция на схеме и количество сохраняются в колонке `Описание`.

## Номер группы

Пока номер группы неизвестен, поле `Номер_группы` остаётся пустым. Позже один номер для всей группы можно указать:

- в `data/data.py` в поле `group_number`;
- аргументом `--group-number`;
- переменной окружения `UTZ74_GROUP_NUMBER`.

## Запуск

```powershell
venv\Scripts\python.exe utz74_site\main.py
```

Проверка на первых десяти уникальных деталях:

```powershell
venv\Scripts\python.exe utz74_site\main.py --limit 10 --delay 0
```

Готовый файл создаётся в `utz74_site/results`, а ссылки на сборочные схемы сохраняются в `utz74_site/data/section_data_list.json`.
