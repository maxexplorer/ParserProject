# Парсер MS-74

Парсер обходит 15 разделов запчастей ДЗ-98, извлекает данные из JSON каждой карточки и формирует Excel в том же формате из 46 колонок, что и `shop_uralaz_site`.

Товары не распределяются по внутренним разделам: для всей выгрузки используется один будущий номер группы ДЗ-98.

## Номер группы

Пока номер неизвестен, поле `Номер_группы` остаётся пустым. Позже его можно указать:

- в `data/data.py` в поле `group_number`;
- аргументом `--group-number`;
- переменной окружения `MS74_GROUP_NUMBER`.

## Запуск

```powershell
venv\Scripts\python.exe ms74_site\main.py
```

Проверка на первых двух товарах:

```powershell
venv\Scripts\python.exe ms74_site\main.py --limit 2 --delay 0
```

Готовый файл создаётся в `ms74_site/results`, а ссылки сохраняются в `ms74_site/data/product_data_list.json`.
